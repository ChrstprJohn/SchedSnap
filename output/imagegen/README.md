# Generated source artwork

Wallpaper templates ready to use live in `public/wallpapers/scenic/<variant-id>/`.
All 55 variants have `mobile.png` (1080 × 2400), `tablet.png` (1600 × 2560), and
`laptop.png` (1920 × 1080). See documentation/SCENIC_TEMPLATES.md for the catalog.

This output folder contains only active marketing originals:

- `marketing/landing/brand/`: logo source.
- `marketing/landing/hero/`: homepage illustration sources.
- `marketing/landing/collections/{mobile,tablet,laptop}/`: collection showcase sources.
- `marketing/how-it-works/`: current generated workflow illustration sources.

Marketing images are not wallpaper templates. Prompt manifests retain historical
provenance, but unused drafts, archives, old wallpaper packs and ZIPs were deleted.
See documentation/IMAGE_ASSETS.md for the current folder map and inventory.
