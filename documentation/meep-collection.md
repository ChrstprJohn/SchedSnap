# Meep collection

Sixteen expressions match the supplied yellow Meep references: tongue, unsure, sweat, grumpy, dizzy, surprised, laughing tongue, heart eyes, blush, angel, happy tears, giddy, puffed cheeks, smile, unamused, and wink. Each has one preset (16 templates total), alternating plain and patterned backgrounds, using one transparent master in `public/images/goofy-mascots/masters/meep-<expression>.png`. Masters retain the generator's original dimensions and pixels, with their longest edge between 1024 and 1536 pixels. Canvas places each face below the schedule on mobile, portrait/landscape tablet, and laptop. The designs use matching warm cream, yellow, and brown palettes, with subtle dots, grids, stripes, or checks.

Generated with the built-in image_gen tool; exact reference roles and current extraction prompts are recorded in `meep-soft-prompts.json`. The original five generation prompts and masters are retained in `meep-prompts.json` and their original generated-image locations. Current cutouts preserve the screenshots' soft outlines, simple shading, expressions, and accessories without added detail, sharpened edges, boosted contrast, or deeper bevels. Source masters are retained locally; immutable Cloudinary delivery metadata is recorded in `src/assets/cloudinaryManifest.js`. No device-specific copies are needed.

The separate Meep gallery category is defined in `src/config/collections.js`; presets live in `src/assets/meepTemplates.js`. Local development previews missing IDs without changing the shared catalog or overriding existing administrator records. The original five IDs and creation dates remain intact.

Validation: transparent backgrounds and solid/near-opaque interiors verified (some tool outputs encode the interior at alpha 254 of 255); no silhouette reaches the image boundary. All 16 presets render five-day schedules on all three device formats. 96 sample/dense Canvas renders preserve every meeting. Overcrowded laptop schedules retain the existing export guard rather than shrinking text beyond the readable limit.

Source changes are developed on `sam/branch`. Artwork uploads are complete; live catalog publication is a separate release step after the frontend merge. When publication is authorized, review the shared catalog with `node scripts/publish-meep-templates.mjs`, then publish with `--publish --expect-revision <reviewed-revision>`. Deploy the frontend containing the Meep category and schema alongside catalog publication. Existing records, hidden designs, administrator overrides, and dates are preserved.
